# Core AI Skills Review — 2026-09-06

Review of the six Core AI skills (`wp-abilities-api`, `wp-abilities-audit`,
`wp-abilities-verify`, `wp-ai-client`, `wp-ai-connectors`, `wp-ai-plugin`)
against their source-of-truth repositories, twelve days after the 1.9.1
release. This is a findings ledger only: no skill, index, marker, or harness
file was changed by this review. It supersedes
`docs/core-ai-skills-audit-2026-08-25.md` for current-state claims and keeps
that document's authority rule and its two-tier separation of source facts
from workflow evidence.

## Authority rule

Executable code at the released tag, then tests shipped at that ref, then the
release changelog/readme, then handbook and announcement prose. Every finding
below cites the upstream file it was read from. Earlier audit documents in
`docs/` were treated as claims under review, never as evidence.

## Method

- Live release discovery against all ten registry sources on 2026-09-06
  (GitHub releases and tags, Packagist, the WordPress.org version-check and
  plugin-information APIs, the WordPress↔Gutenberg version map).
- Deterministic gates run on the committed tree, then the index updater run in
  a throwaway copy of the tree to see what a refresh would change.
- Every upstream cloned at its pinned tag, plus Gutenberg v23.9.0, the
  WordPress 7.1 release package (SHA-256
  `d1ae02b5ae18428031ffc3943659fa87ab361d827f4aa804adf9276e4dc75df6`), and
  single files from the `6.9`, `7.0`, and `trunk` branches of
  `wordpress-develop`.
- Six independent verification passes over the reference files (about 6,000
  lines), one per skill area, each reporting only discrepancies it could cite.
- Link health for all 29 URLs the six skills cite; `skills-ref validate` on
  all six skills; the AI Client detector run against three upstream trees.
